This is an android app (targeting android 8+) to connect to an ESP32 inside a Greenpower F24 car's steering wheel to a phone used for a radio and telemetry

The app needs a few components
Discord is used for radio
TaskDroid is called to interact with discord's notification for push to talk

The ESP32 should be wired up to: 
 2 buttons - radio push to talk and pit confirm  (configureable in task droid)
 1 potentiomenter - volume
